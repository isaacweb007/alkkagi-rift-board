# 최초 원화 보존형 3D 경기 — 흑백 팀·스킬·사운드

## 제작 원칙

- `character-roster.png`의 최초 캐릭터 10종을 디자인 기준으로 고정한다.
- `arena-*-danger-v2.png`의 중세·현대·미래 위험 배경을 실제 WebGL 경기 뒤에 그대로 사용한다.
- `board-topdown.png`의 청동 테두리, 방사형 석판, 중앙 꽃 문양을 중복 캐릭터가 없는 실제 3D 판 재질로 재구성한다.
- 캐릭터 장비 색은 원화를 유지하고, 몸체와 팀 밴드만 흑돌·백돌로 바꿔 피아 식별성을 확보한다.

## 흑돌·백돌 팀

- 매 경기 플레이어가 흑돌 또는 백돌로 무작위 배정된다.
- 상대는 자동으로 반대 색이 된다.
- 몸체, 하단 팀 밴드, HUD 심볼, 생존 표시를 같은 색 체계로 묶었다.
- 선공 무작위와 팀 색상 무작위는 서로 독립적이다.

## 사운드와 임팩트

- 전체 음량, 충돌·효과음, 배경 음악을 독립적으로 조절한다.
- 한 번에 전체 음소거/해제가 가능하다.
- 아레나별 저음 루트와 펄스가 다른 절차형 배경 음악을 사용한다.
- 충돌음은 고역 어택과 저역 타격음을 겹쳐 재생한다.
- 번개, 천둥, 물, 불 속성별 레이어는 기존 타격음 위에 추가된다.
- 모든 유효 충돌에 확장형 3D 충격파와 입자, 섬광, 카메라 흔들림을 적용한다.
