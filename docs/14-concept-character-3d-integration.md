# 원화 캐릭터 10종 3D 경기 통합 — ALPHA 0.4

## 목표

임시 원통·뿔 조합이 아니라 최초 콘셉트 원화에서 확정한 10종 캐릭터를 실제 WebGL 경기 돌로 사용한다. 모든 돌은 동일한 물리 충돌 반지름을 유지하면서 원화 데칼과 캐릭터별 3D 실루엣으로 구분한다.

## 게임 적용 로스터

| 원화 위치 | 캐릭터 | 3D 식별 장비 |
|---|---|---|
| 상단 1 | 몽돌 | 기본 흑석과 작은 크레스트 |
| 상단 2 | 브릭 경 | 황동 투구, 바이저, 중앙 장식 |
| 상단 3 | 루나벨 | 보라색 마법 모자와 구슬 |
| 상단 4 | 핀치 | 태엽 열쇠와 청록색 모노클 |
| 상단 5 | 번개배달 모모 | 청색 헬멧 밴드, 측면 포드, 가방 |
| 하단 1 | 비트캣 | 고양이 귀, 네온 헤드폰 |
| 하단 2 | 세이프티 박사 | 노란 안전모와 전면 램프 |
| 하단 3 | 제로-볼트 | 육각 배치의 청록 결정 왕관 |
| 하단 4 | 코멧 키드 | 붉은 혜성 깃과 별 장식 |
| 하단 5 | 오로라-8 | 여덟 색상의 발광 꽃잎 |

## 렌더링 방식

- 기존 `character-roster.png`를 5×2 아틀라스로 사용한다.
- 각 3D 돌 상단의 원형 데칼에 해당 캐릭터 원화를 직접 매핑한다.
- 선택 UI에는 같은 원화의 고해상도 크롭을 표시한다.
- 장비는 Three.js 기하학과 PBR 재질로 입체 제작하며 원화의 대표 실루엣을 따른다.
- 아레나는 기존 중세 용암성, 현대 번개 도시, 미래 중력 우물 원화 배경을 유지한다.
- 장식은 충돌 판정에 포함하지 않아 캐릭터별 외형 차이가 승패에 영향을 주지 않는다.

## 팀 구성

- 5:5에서는 원화 10종이 한 경기에 모두 등장한다.
- 3:3에서는 각 진영의 앞 3종을 사용한다.
- 연습 AI 진영은 원화 캐릭터를 붉은 시선·팀 링으로 오염된 경쟁자처럼 표현한다.

## 검증

- PC 1440×900에서 원화 선택 패널, 10종 3D 실루엣, 용암성 배경 확인
- 좁은 화면에서도 선택 원화 카드가 유지되는 반응형 UI 확인
- 텍스처 로딩 전 빈 이미지 경고 제거
- WebGL 오류와 새 콘솔 경고 없음
- 빌드·린트·자동 테스트 17개 통과
