# 핵심 규칙과 게임 모드

## 제품 정의

- 대상: 물리 퍼즐과 짧은 대전을 좋아하는 13세 이상 PC 웹 이용자. 현금성 기능이 열리는 지역에서는 별도 성인·신원 요건을 적용한다.
- 한 판 목표 시간: 5–8분, 하드 캡 10분을 시작 가설로 둔다.
- 시점: 35–45도 탑다운 3D, 제한적 회전과 즉시 복귀 버튼.
- 기본 입력: `돌 선택 → 발사 반대 방향으로 당기기 → 당구식 파워 게이지/미세 힘 조절 → 놓기`.
- 핵심 승리 조건: 상대 돌 8개를 먼저 모두 판 밖으로 떨어뜨린다.
- 핵심 턴 규칙: 기본은 번갈아 한 번씩 진행하되, **한 샷으로 상대 돌을 하나 이상 떨어뜨리면 같은 플레이어가 보너스 샷을 한 번 더 얻는다.**

## 디자인 기둥

1. **한 번에 이해, 오래 숙련**: 입력은 하나지만 접촉점, 힘, 회전, 반사, 포지셔닝이 깊이를 만든다.
2. **보이는 물리**: 결과가 캐릭터 등급이나 숨은 확률이 아니라 화면에서 납득되어야 한다.
3. **마지막 한 알의 역전**: 수적 열세에서도 정확한 한 방으로 돌아올 가능성을 남긴다.
4. **캐릭터는 개성, 결제는 표현**: 랭크의 승패는 지출액과 분리한다.
5. **웹에서 즉시 시작**: 게스트가 지갑 없이 첫 샷까지 30초 안에 도달하는 것을 목표로 한다.

## 명시적 비목표

- 출시부터 오픈 마켓, NFT 거래, 무제한 토큰 출금을 제공하지 않는다.
- 캐릭터 장식마다 다른 물리 충돌체를 사용하지 않는다.
- 랭크 표준판에 랜덤 폭발, 확률 치명타, 유료 부활을 넣지 않는다.
- 완벽한 전체 경로 예측선을 제공하지 않는다.
- 모바일 동시 출시를 초기 목표로 잡지 않는다.

## 표준 대전 규칙

### 준비

- 각 플레이어는 원형 충돌체가 동일한 돌 8개를 대칭 배치 구역 안에 놓는다.
- 입문 구간은 자동 추천 배치 3종만 제공한다. 숙련 구간은 제한 시간 안에 직접 배치할 수 있다.
- 장식, 모자, 망토, 꼬리는 렌더링 요소일 뿐 충돌 판정에 포함하지 않는다.
- 선공은 서버가 결정하고 경기 기록에 남긴다. 랭크 선공 승률이 허용 범위를 벗어나면 규칙을 조정한다.

### 한 턴

1. 움직임이 완전히 멈추면 활성 플레이어의 턴이 시작된다.
2. 살아 있는 자기 돌 하나를 선택한다.
3. 마우스를 발사 반대 방향으로 당겨 조준하고, 당구식 힘 게이지로 0–100 파워를 정한다. `Shift`를 누르는 동안 감도를 25%로 낮추고 마우스 휠로 ±1씩 미세 조절할 수 있다.
4. 25초 안에 회전까지 정한 뒤 버튼을 놓아 발사한다. 우클릭 또는 `Esc`는 발사 전 취소다. 수치는 테스트 전 시작 가설이다.
5. 서버가 입력을 검증하고 권위 물리 시뮬레이션을 실행한다.
6. 모든 돌이 정지하거나 안전 타임아웃에 도달하면 낙하 판정을 확정한다.
7. 상대 돌이 하나 이상 떨어졌고 경기가 끝나지 않았다면 `BONUS SHOT`을 밝히고 같은 플레이어의 20초 보너스 턴을 시작한다. 그렇지 않으면 상대에게 턴이 넘어간다.

### 보너스 샷 — 게임 고유 규칙

- 한 샷에서 상대 돌을 1개 또는 여러 개 떨어뜨려도 예약되는 보너스 샷은 **한 번**이다.
- 보너스 샷에서도 다시 상대 돌을 떨어뜨리면 보너스 샷이 다시 이어진다. 잘 치는 동안 연속 턴을 만들 수 있다.
- 자기 돌과 상대 돌이 함께 떨어져도 상대 돌을 하나 이상 제거했고 자기 돌이 남아 있다면 보너스 샷을 얻는다.
- 상대 돌을 떨어뜨리지 못했거나 자기 돌만 떨어뜨리면 즉시 턴을 넘긴다.
- 상대의 마지막 돌이 떨어지면 즉시 승리하며 불필요한 보너스 샷은 진행하지 않는다.
- 여러 개를 떨어뜨렸다고 보너스 샷을 누적하지 않는다. 이 제한이 한 번의 대박 샷이 경기 전체를 자동으로 끝내는 것을 막는다.

플레이어가 시간을 넘기면 약한 자동 샷을 강제하지 않고 **턴 패스** 처리한다. 반복 지연은 매치 패배와 매너 점수 조정 대상으로 둔다.

### 조준 정보

- 표시: 발사 방향, 힘 게이지, 선택 돌의 짧은 초기 궤적, 첫 접촉 예상점.
- 미표시: 모든 연쇄 충돌의 완전한 결과, 상대 돌의 최종 위치, 확정 낙하 여부.
- 정밀 수치가 높으면 힘 게이지의 세밀 구간이 넓어지지만, 실제 플레이어 입력을 자동 보정해 주지는 않는다.
- 마우스와 키보드의 보조 입력을 모두 지원하며 랭크에서 입력 장치별 예측 정보는 동일하다.

### 당구식 파워 게이지

- **0–69 제어 구간**: 파란색. 구출, 얇은 맞히기, 위치 조정에 적합하다.
- **70–89 강타 구간**: 금색. 공격과 자멸 위험이 균형을 이루는 주력 구간이다.
- **90–100 MAX 구간**: 붉은색. 최대 추진력을 확실히 낼 수 있지만 반동·연쇄·자기 추락 위험도 화면에 함께 경고한다.
- 100에는 자석처럼 붙는 짧은 `MAX 스냅`을 둬 픽셀 단위로 최대치를 찾지 않아도 된다. 이는 자동 조준이 아니라 입력 편의 기능이다.
- 최대 파워를 넘는 숨은 확률, 랜덤 치명타, 유료 파워 부스트는 없다. 같은 입력과 같은 물리 상태는 항상 같은 결과를 낸다.

### 낙하와 승리

- 돌 중심이 판의 유효 지지 경계를 넘고 아래 낙하 볼륨에 진입하면 탈락한다.
- 한 샷에서 양쪽 마지막 돌이 동시에 떨어지면, 해당 샷을 한 플레이어의 돌이 먼저 탈락했는지 서버 타임라인으로 판정한다.
- 완전히 동일한 시뮬레이션 틱이면 무승부 처리한다. 랭크에서는 짧은 타이브레이커 판으로 넘어간다.
- 10분 하드 캡 시 남은 돌 수가 많은 쪽이 승리한다. 같으면 살아 있는 돌들의 판 중심까지 거리 합이 작은 쪽이 이긴다. 이 조건은 초기 테스트 후 재검토한다.

### 연결 끊김과 부정행위

- 짧은 연결 끊김에는 재접속 유예를 제공한다. 물리 결과는 서버에서 계속 보존한다.
- 경기 기록에는 초기 상태, 샷 벡터, 회전, 캐릭터/튜닝 ID, 서버 물리 버전, 결과 해시를 저장한다.
- 클라이언트가 보낸 최종 위치는 신뢰하지 않는다.
- 같은 물리 버전으로 경기를 재생할 수 있어야 랭크와 현금성 기능을 열 수 있다.

## 5대 공통 능력치

모든 캐릭터는 1–5 범위의 다섯 수치를 사용하며 랭크형 총합은 15점으로 고정한다.

| 능력치 | 플레이 체감 | 강점 | 대가 |
|---|---|---|---|
| 추진력 | 같은 충전에서 초기 속도가 높음 | 장거리, 강한 개시 | 과진입과 자멸 위험 |
| 중량 | 밀리지 않고 운동량을 잘 전달 | 방어, 정면 충돌 | 섬세한 재배치가 어려움 |
| 내구 | 충돌·반사 뒤 에너지를 더 보존함 | 연쇄 충돌, 벽 반사, PvE 상태 저항 | 멈춰야 할 때 과진입하기 쉬우며 추가 생명은 없음 |
| 정밀 | 미세 힘 조절 구간이 넓음 | 세이브, 얇은 맞히기 | 폭발적 힘이 낮을 수 있음 |
| 회전 | 곡선과 접촉 뒤 방향 변화가 큼 | 우회, 뱅크, 변칙 | 예측 난도가 높음 |

## 업그레이드 원칙

사용자가 원하는 성장 감각은 세 층으로 분리한다.

### 마스터리 레벨 — 모든 모드

- 플레이로 경험치를 얻어 표정, 재질, 승리 포즈, 등장 연출, 음성, 궤적을 연다.
- 레벨 숫자는 애착과 숙련을 보여 주지만 랭크 능력치를 올리지 않는다.

### 튜닝 모듈 — 랭크 사이드그레이드

- 예: 추진력 +1을 얻으면 정밀 -1처럼 총합 15를 유지한다.
- 각 모듈은 경기 전에 상대가 확인할 수 있고, 무료 플레이로도 동일하게 획득 가능해야 한다.
- 메타를 고착시키는 조합은 시즌 단위로 조정하되 구매 상품의 외형 소유권은 유지한다.

### 모험 강화 — 싱글/PvE 전용

- 보스 방어막 파괴, 상태효과 저항, 추가 퍼즐 도구처럼 수치 성장을 허용한다.
- `모험 전용`을 UI에 크게 표시하고 랭크 로드아웃으로 가져갈 수 없게 한다.

## 게임 모드

### 싱글

- **시공 캠페인**: 마스터 시나리오의 3막 진행.
- **트릭샷 연구소**: 정해진 샷 수 안에 특정 돌만 떨어뜨리는 물리 퍼즐.
- **연습장**: 마찰, 예상선, 샷 되감기, 느린 재생을 자유롭게 사용.
- **AI 대전**: 입문·숙련·전문 난이도. 전문 AI도 입력 오차와 사고 시간을 가져 인간적으로 보이게 한다.

### 대전

- **친선전**: 방 코드, 관전자, 규칙 프리셋. 경제 보상 없음.
- **캐주얼 1대1**: 빠른 매칭, 표준 규칙, 낮은 부담의 시즌 경험치.
- **랭크 1대1**: 서버 권위, 리플레이, 안티치트, 고정된 표준판. 능력치 총합 15.
- **이벤트전**: 스토리 장애물, 팀전, 제한 로스터를 순환 제공하되 랭크와 분리한다.

## 아레나 공정성

- 중세·현대·미래 아레나는 랭크에서 시각과 소리만 다르고 판 크기, 마찰, 복원력, 경계 형상은 같은 표준 프리셋을 사용한다.
- 모든 아레나는 판 아래의 깊고 위험한 공간을 카메라에서 분명하게 보여 준다. 중세는 용광로 심연, 현대는 초고층 낙하, 미래는 중력 소용돌이를 사용해 가장자리 자체가 긴장을 만든다.
- 비, 눈, 홀로그램, 관중은 조준선을 가리거나 프레임 타임을 흔들지 않아야 한다.
- 스토리/이벤트 변형판의 경사, 이동 발판, 바람은 규칙 선택 화면에 명시한다.

## 초기 밸런스 목표

- 선공 승률: 48–52% 범위를 목표 가설로 둔다.
- 동일 실력대 캐릭터 승률: 47–53% 범위를 경보선으로 둔다.
- 평균 턴 수: 12–18턴.
- 첫 세 턴 안에 돌 4개 이상이 탈락하는 경기 비율을 추적해 지나친 원턴 폭발을 막는다.
- 자멸 샷 비율과 취소율을 신규·숙련 집단별로 분리 측정한다.

## 플레이테스트 합격 기준

- 처음 보는 사용자가 설명 없이 60초 안에 유효 샷을 성공한다.
- 숙련 사용자가 힘뿐 아니라 접촉점·회전·뱅크·세이브를 의도적으로 구분해 사용한다.
- 결과에 불만을 가진 사용자가 리플레이를 보고 물리 원인을 설명할 수 있다.
- 카메라 모션과 음악을 꺼도 승부에 필요한 정보가 남는다.
- 유료 캐릭터를 보았을 때 “강해서 샀다”보다 “내 스타일이라 샀다”는 반응이 우세하다.

## 아직 결정하지 않은 핵심 항목

- 선공 보정이 필요한지, 필요하다면 배치권·재대결 우선권·세트제 중 무엇이 가장 공정한지.
- 랭크를 단판 8대8로 할지, 짧은 라운드 세트로 바꿀지.
- 회전을 마우스 휠, 보조 드래그, 키 입력 중 어떤 방식으로 줄지.
- 캐릭터 혼합 8개 팀에서 같은 캐릭터의 중복을 몇 개까지 허용할지.
