# 원화 기반 3D 모델 패스와 와이드 아레나 밸런스

## 이번 제작 목표

- 최초 원화 10종의 실루엣과 재질을 실제 WebGL 경기 모델에 반영한다.
- 납작한 퍽처럼 보이던 돌을 둥근 석재 캐릭터로 개선한다.
- 판이 작아 한 번의 충돌로 쉽게 탈락하던 문제를 줄인다.
- 약한 충돌은 가장자리에서 버티고, 강한 정타는 링아웃으로 이어지게 한다.

## 3D 모델 패스

- 원본 `character-roster.png`를 디자인 기준으로 삼아 10종의 PBR 3D 렌더 시트를 제작했다.
- 게임용 렌더 시트: `concept-site/public/assets/character-roster-3d-v2.png`
- 모든 캐릭터의 몸체를 원기둥에서 세로로 눌린 구형 석재 메시로 변경했다.
- 바닥 받침, 금속 외곽 링, 흰 눈, 검은 동공, 입체 눈썹과 입을 별도 메시로 구성했다.
- 기사 투구, 마법 모자, 태엽 장치, 배달 헬멧, 고양이 헤드셋, 안전모, 크리스털, 코멧 깃, 오로라 광석을 각각 독립 3D 장비로 유지했다.
- 캐릭터 선택 패널과 모델 상단 데칼은 새 3D 렌더 시트를 사용한다.

## 와이드 아레나 밸런스

| 항목 | 이전 | 변경 |
|---|---:|---:|
| 판 반지름 | 4.60 | 5.75 |
| 안전 반지름 | 4.17 | 5.31 |
| 플레이 면적 | 100% | 약 156% |
| 최대 발사 속도 | 기준 100% | 약 89% |
| 충돌 반발 계수 | 0.86–0.96 | 0.78–0.88 |

가장자리 0.78 유닛 구간은 `EDGE GRIP ZONE`이다. 바깥 방향 속도만 점진적으로 감쇠하며 안쪽으로 돌아오는 움직임은 방해하지 않는다. 따라서 빗맞은 약한 충격은 생존할 가능성이 커지고, 최대 파워의 정타·연쇄 충돌·각도 샷은 여전히 링아웃을 만든다.

## 검증 기준

- 5:5 배치 화면에서 캐릭터 10종이 서로 다른 실루엣으로 보여야 한다.
- AI의 첫 충돌을 받은 돌이 낮은 충격에서는 가장자리에서 즉시 탈락하지 않아야 한다.
- 원 안쪽으로 움직이는 돌에는 그립 감쇠가 적용되지 않아야 한다.
- 기존 턴 교대, 상대 링아웃 시 보너스 샷, 승패 판정과 리플레이는 유지되어야 한다.
