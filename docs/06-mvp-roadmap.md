# PC 웹 MVP 제작 로드맵

## 제작 전략

한 번에 10개 캐릭터와 Web3 출금까지 만드는 대신, 위험이 큰 순서대로 증명한다.

`손맛이 있는 물리 → 재현 가능한 온라인 대전 → 3D 콘텐츠 생산성 → 경제와 운영 → 규제된 현금성 기능`

앞 단계의 합격 기준을 통과하지 못하면 다음 단계의 범위를 늘리지 않는다.

## 단계 0 — 물리 그레이박스

### 만든다

- 장식 없는 원형 돌 8대8.
- 회색 표준판 1개.
- 마우스 선택·드래그·힘·회전·놓기.
- 고정 시점 카메라와 판 전체 복귀.
- 낙하, 승리, 무승부, 하드 타임아웃.
- 샷 입력과 결과를 저장하는 로컬 리플레이.

### 아직 만들지 않는다

- 계정, 상점, 토큰, 스토리 컷신, 10개 캐릭터, 화려한 아레나.

### 통과 조건

- 처음 보는 사용자가 60초 안에 유효 샷을 성공한다.
- 같은 초기 상태와 샷 입력이 같은 물리 버전에서 같은 결과를 낸다.
- 힘·접촉점·회전·뱅크의 차이가 사람이 느낄 만큼 분명하다.
- 한 판이 목표 시간에 들어오고 멈춤 상태 판정이 안정적이다.

## 단계 1 — 오프라인 버티컬 슬라이스

### 만든다

- `노을의 원탁` 아레나 한 개의 최종 품질 샘플.
- 몽돌, 브릭 경, 루나벨 3종의 최종에 가까운 3D 모델과 애니메이션.
- 튜토리얼 3스테이지와 AI 대전.
- T0–T4 충돌음, 낙하, 턴 전환, 기본 음악 스템.
- 팀 색상, 조준선, 위험 경계, 결과 UI.
- 저·중·고 그래픽 옵션과 접근성 옵션.

### 통과 조건

- 강타와 낙하가 일반 접촉보다 확실히 강하게 느껴지되 조준을 방해하지 않는다.
- 캐릭터 장식을 바꿔도 충돌 결과가 바뀌지 않는다.
- 목표 PC 웹 환경에서 60 fps 프레임 예산을 지킨다.
- 음악·카메라 모션을 꺼도 핵심 정보가 남는다.
- 20명 이상 관찰 테스트에서 반복 플레이 의사가 확인된다. 표본 수는 예산에 맞춰 확정한다.

## 단계 2 — 온라인 권위 서버 알파

### 만든다

- 게스트 계정과 선택적 계정 연결.
- 캐주얼 1대1 매칭, 방 코드 친선전.
- 서버 권위 샷 검증과 물리 결과.
- 재접속, 턴 타이머, 기권, 비정상 종료 처리.
- 물리 버전이 포함된 서버 리플레이.
- 기본 매치메이킹, 신고, 차단, 관전 제한.
- 네트워크 지연 보정 중 오디오/VFX 중복 방지.

### 통과 조건

- 일반적인 지연과 짧은 패킷 손실에서 턴 진행과 결과가 갈라지지 않는다.
- 재접속 뒤 현재 상태와 남은 시간이 복원된다.
- 클라이언트 변조로 최종 위치·승패를 바꿀 수 없다.
- 서버 기록만으로 분쟁 경기를 재생할 수 있다.

## 단계 3 — 콘텐츠 베타

### 만든다

- 중세·현대·미래 아레나 3종.
- 캐릭터 10종과 공통 애니메이션 세트.
- 프롤로그 10경기와 3막 캠페인.
- 연습장, 트릭샷 연구소, AI 3단계.
- 캐주얼·랭크·친선전.
- 마스터리, PP, 비현금 상점, 무료 체험 로테이션.
- 운영 대시보드와 밸런스 텔레메트리.

### 통과 조건

- 랭크의 모든 아레나가 같은 물리 프리셋을 사용한다.
- 캐릭터 승률과 선공 승률이 경보 범위 안에 들어온다.
- 결제 여부가 랭크 성과와 유의미한 전투력 차이를 만들지 않는다.
- 10개 캐릭터를 같은 품질로 반복 생산할 수 있는 모듈러 파이프라인이 검증된다.
- 첫 10경기 동안 지갑·토큰·출금 유도가 없다.

## 단계 4 — PC 웹 1.0 출시

### 출시 범위

- 싱글 캠페인, 연습/퍼즐, AI.
- 친선, 캐주얼, 랭크 1대1.
- 3개 시대 아레나, 캐릭터 10종.
- 비현금 PP/PC 경제와 직접 구매 상점.
- 시즌 0 마스터리와 기본 라이브 이벤트.
- 한국판 현금성 출금 비활성화.

### 출시 전 체크

- 등급분류, 이용약관, 개인정보, 청소년 보호, 결제/환불, 오픈소스·에셋 라이선스.
- 장애 대응, 롤백, 고객지원, 신고, 제재, 리플레이 보존 기간.
- 저사양·브라우저·그래픽 드라이버 조합 테스트.
- 부하 테스트, DDoS 대비, 계정 탈취와 결제 사기 대응.
- 접근성, 자막, 색각, 카메라 모션 감소 검수.

## 단계 5 — Web3 소유 기능

현금성 대전보다 먼저 위험이 낮은 선택적 소유 기능만 검토한다.

- 지갑 없이도 사용 가능한 계정 추상화.
- 사용자가 명시적으로 원할 때만 외부 지갑 연결.
- 외형 소유 증명 또는 플랫폼 간 프로필처럼 게임 승패와 무관한 항목.
- 체인 장애 시에도 매치·상점 조회·기본 소유 확인이 멈추지 않는 캐시/복구 설계.
- 거래 가능성을 열 경우 사기, 저작권, 가격 표시, 마켓 수수료, 지원 범위를 별도 검토.

## 단계 6 — 현금성 경쟁 파일럿

다음 모두를 충족할 때만 허용 국가의 소규모 초대 파일럿으로 진행한다.

- 대상 국가별 서면 법률 의견과 필요한 허가·등록·등급 절차 완료.
- 한국 빌드·IP·거주자 차단 정책 검증.
- KYC/AML, 제재 검사, 자금 출처, 세금, 한도, 자가 제외.
- 독립 원장과 별도 매치 큐.
- 서버 권위 리플레이, 공모·봇·다중 계정 탐지.
- 이용자 자산 분리, 키 관리, 외부 보안 감사, 비상 중지.
- 입금·매치·출금 수수료와 가격 이탈 정책의 명확한 고지.

## 권장 시스템 경계

```text
브라우저 클라이언트
  ├─ 3D 렌더링·입력·UI
  ├─ 로컬 예측(표시용)
  └─ 오디오·VFX·접근성
          │ 샷 입력
          ▼
권위 매치 서비스
  ├─ 턴·규칙 검증
  ├─ 물리 시뮬레이션
  ├─ 리플레이·결과 해시
  └─ 재접속 상태
          │ 확정 결과
          ▼
계정·콘텐츠 서비스
  ├─ 로스터·마스터리
  ├─ PP/PC 비현금 원장
  ├─ 상점·시즌
  └─ 신고·제재

[후기 별도 경계]
규제 파일럿 서비스
  ├─ KYC/AML·지역 정책
  ├─ WB 독립 원장
  ├─ 보관/결제 파트너
  └─ 출금·정산·분쟁
```

블록체인 확인을 샷 처리나 턴 진행의 동기 경로에 넣지 않는다.

## 웹 성능 예산 — 시작 가설

- 게임플레이: 60 fps, 프레임당 16.67 ms.
- 첫 플레이 셸: 압축 전송 25 MB 이하를 목표로 하고 아레나는 필요 시 스트리밍.
- 한 아레나 추가 다운로드: 35 MB 이하 목표.
- 메모리: 일반 데스크톱 브라우저 탭 1.2 GB 이하 목표.
- 중요 오디오 원샷: 경기 전에 프리로드.
- 스킨과 배경 로딩 실패가 표준 충돌체·팀 표시·게임 규칙을 깨지 않게 폴백 제공.

이 수치는 버티컬 슬라이스 실측으로 수정한다.

## 필요한 핵심 역할

- 게임 디렉터/시스템 기획: 물리 규칙, 밸런스, 모드, 경제 경계.
- 클라이언트/3D 엔지니어: 렌더링, 입력, 카메라, VFX, 성능.
- 서버/네트워크 엔지니어: 권위 매치, 재접속, 리플레이, 매칭.
- 테크니컬 아티스트: 캐릭터 모듈화, 셰이더, 아레나 최적화.
- 3D 캐릭터/환경 아티스트와 애니메이터.
- 사운드 디자이너/작곡가: 이벤트 기반 충돌음과 적응형 음악.
- UI/UX 디자이너: 조준, 상점, 접근성, 지갑 선택 흐름.
- QA/데이터: 결정성, 브라우저, 밸런스, 퍼널, 부정행위 테스트.
- 보안·법률·컴플라이언스: 현금성 단계 진입 전 필수.

## 주요 위험과 우선 대응

| 위험 | 영향 | 첫 대응 |
|---|---|---|
| 브라우저/서버 물리 불일치 | 승패 분쟁 | 서버 권위, 동일 버전 리플레이, 입력만 전송 |
| 장식이 조준을 가림 | 불공정·가독성 저하 | 공통 판정체, 장식 안전 영역, 카메라 거리 QA |
| 8대8 경기 장기화 | 이탈 | 턴 시간·배치·마찰·하드 캡 플레이테스트 |
| 유료 캐릭터 P2W 인식 | 신뢰 하락 | 15점 예산, 무료 체험, 승률 공개, 직접 구매 |
| 3D 웹 초기 로딩 | 첫 경기 이탈 | 셸 우선, 아레나 스트리밍, 텍스처/메시 압축 |
| 연쇄 충돌 오디오 과밀 | 피로·클리핑 | 동시 재생 그룹, 변형, 저역 제한, 우선순위 |
| 현금성 기능의 규제 충돌 | 출시 차단 | 한국판 분리, 후기 게이트, 외부 전문 검토 |
| 토큰이 재미보다 앞섬 | 리텐션 실패 | 첫 10경기 무지갑, 토큰 KPI보다 재미 KPI 우선 |

## 개발 텔레메트리 최소 세트

- 튜토리얼 단계별 시작·완료·재시도·이탈.
- 조준 시간, 충전량, 회전량, 접촉점, 자멸 여부.
- 턴 수, 경기 길이, 선공, 남은 돌 수, 역전 여부.
- 캐릭터/튜닝/아레나별 선택률과 승률.
- 프레임 타임, 메모리, 로딩 실패, 오디오 지연 이벤트.
- 재접속, 기권, 신고, 의심 샷, 리플레이 재현 실패.
- 상점 노출·체험·구매는 첫 10경기 이후부터만 기록/실험.

## 바로 다음 제작 순서

1. 회색 판과 몽돌 16개로 오프라인 물리 프로토타입.
2. 20–30개의 대표 샷을 `골든 리플레이`로 저장.
3. 입력·카메라·낙하 판정 플레이테스트.
4. 노을의 원탁과 몽돌·브릭·루나벨로 버티컬 슬라이스.
5. 타격감 T0–T4와 핵심 이벤트 12개를 구현.
6. 재미와 결정성이 합격한 뒤에만 서버 권위 온라인 대전으로 확장.
