# 실제 게임 제작 엔진 착수 V1

## 이번 단계에서 시작한 실제 엔진

새 `/arena` 경로는 콘셉트 이미지를 설명하는 화면이 아니라 Three.js/WebGL로 직접 렌더링되는 실제 게임 실행 화면이다.

- 3D 원형 아레나, 금속 측면, 발광 경계, 19×19 격자 재질
- 원근 카메라, 실시간 그림자, 헤미스피어·스폿·위험 지대 광원
- 몸체, 발광 테두리, 눈, 입, 뿔·왕관·안테나·보석이 조립된 3D 캐릭터 돌
- PC와 터치 좌표를 3D 보드 좌표로 변환하는 레이캐스팅
- 120Hz 고정 스텝 원형 충돌, 질량 임펄스, 마찰, 회전 커브
- 안전 반경을 벗어났을 때 중력 낙하·회전·비명 처리
- 불·물·번개·천둥·공허별 광원, 파티클, 전기 아크와 합성음
- 3:3, 5:5, 20초 배치, 랜덤 선공, 턴 제한, 링아웃 보너스 샷
- AI 레벨별 반응 속도, 조준 오차, 가장자리 표적 우선순위
- 기존 D1 프로필·XP·Play Point API 연결

## 실제 제품이 되기 위한 제작 레이어

| 레이어 | 현재 | 다음 제작 목표 |
|---|---|---|
| 렌더링 | 절차형 Three.js 캐릭터와 보드 | Blender 제작 GLB 캐릭터, PBR 텍스처, LOD |
| 물리 | 브라우저 고정 스텝 원형 충돌 | 서버와 공유하는 고정소수점 결정론 물리 |
| 대전 | 완성된 로컬 AI 경기 | Durable Object 기반 실시간 1:1 경기 |
| 입력 | 마우스·포인터 배치와 당겨쏘기 | 모바일 감도, 게임패드, 리플레이 입력 기록 |
| 연출 | 파티클·조명·카메라 흔들림·합성음 | 아티스트 VFX, 캐릭터별 녹음 음성, 음악 스템 |
| 캐릭터 | 능력치와 절차형 외형 10종 | 리깅·표정·스킨·장비·업그레이드 제작 파이프라인 |
| 경제 | 출금 불가 테스트 PP·XP | 규제·보안 검증 후 별도 토큰 경제 |

## 다음 스프린트 우선순위

1. 실제 GLB 캐릭터 3종과 보드 1종을 Blender에서 제작하고 웹 최적화 기준을 고정한다.
2. 현재 물리 코어를 순수 TypeScript 패키지로 분리해 브라우저와 서버가 동일 코드를 사용하게 한다.
3. 경기별 Durable Object와 WebSocket 프로토콜을 만들고 배치·샷·턴을 서버가 소유하게 한다.
4. 두 브라우저 간 3:3 경기를 연결하고 지연 보간·재접속·턴 시간 초과를 검증한다.
5. 서버가 생성한 경기 결과만 XP와 테스트 PP에 반영하도록 결과 API를 잠근다.
6. 리플레이 입력 로그, 관전자 스냅샷, 부정행위 탐지용 텔레메트리를 추가한다.

## 아트 제작 기준

- 캐릭터 한 종: 20–35K triangle, 2K PBR texture atlas, 3단계 LOD.
- 아레나 한 종: 정적 메시 120K triangle 이하, 위험 배경은 분리된 저비용 파티클 레이어.
- 표정: 기본, 조준, 발사, 충돌, 가장자리 공포, 추락 6상태.
- 웹 첫 로딩: 핵심 번들·첫 아레나·출전 캐릭터 합계 15MB 이하 목표.
- 나머지 캐릭터와 아레나는 로비에서 선택할 때 지연 로딩한다.

## 완료 기준

이 단계의 완료 기준은 사용자가 `/arena`에서 3:3 또는 5:5를 선택하고, 20초 배치 후 자신의 입체 돌을 당겨 발사하며, 충돌·원소 효과·추락·AI 반격·보너스 샷·승패까지 한 경기를 마칠 수 있는 것이다.
