# 알까기 핵심 게임성 V2

## 한 문장 정의

귀여운 바둑알 캐릭터 하나를 마우스나 손으로 발사 반대 방향으로 당기고, 당구처럼 방향과 힘을 조절해 상대 돌을 위험한 아레나 아래로 떨어뜨리는 턴제 3D 물리 대전이다.

## 실제 알까기에서 지켜야 할 뼈대

확인한 설명들의 공통점은 다음과 같다.

- 두 플레이어가 같은 수의 자기 돌을 놓는다.
- 번갈아 자기 돌 하나를 손가락으로 튕긴다.
- 충돌로 상대 돌을 판 밖으로 내보낸다.
- 자기 돌도 함께 떨어질 수 있어 공격과 자멸 위험이 항상 붙어 있다.
- 상대 돌을 모두 제거하고 마지막 돌을 남긴 쪽이 이긴다.
- 한 번에 여러 돌을 밀어내는 `일타다피`가 가장 큰 구경거리다.

참고: [알까기 개요](https://en.wikipedia.org/wiki/Alkkagi), [교육용 알까기 활동 설명](https://image.aladin.co.kr/img/banner/cid/react/8901274205.pdf), [디지털 알까기 설명](https://play.google.com/store/apps/details?id=com.alkagi)

`상대 돌을 떨어뜨리면 한 번 더`는 보편적 단일 표준으로 확인된 규칙이 아니라, 이 프로젝트가 콤보와 역전의 손맛을 위해 채택하는 **게임 고유 규칙**이다.

## 확정 턴 흐름

```text
내 턴 시작
  → 살아 있는 내 돌 선택
  → 반대 방향으로 당겨 조준
  → 파워 0–100 + 회전 + 미세 힘 조절
  → 놓아서 발사
  → 모든 돌이 멈춤
  → 상대 돌이 떨어졌는가?
       ├─ 아니오: 상대 턴
       └─ 예: 경기가 끝나지 않았다면 BONUS SHOT
                    └─ 다시 떨어뜨리면 연속 BONUS SHOT
```

### 보너스 샷 판정표

| 한 샷의 결과 | 다음 진행 |
|---|---|
| 아무도 떨어지지 않음 | 상대 턴 |
| 내 돌만 떨어짐 | 상대 턴 |
| 상대 돌 1개 떨어짐 | 내 보너스 샷 1회 |
| 상대 돌 여러 개 떨어짐 | 내 보너스 샷 1회, 누적 없음 |
| 양쪽 돌이 함께 떨어짐 | 상대 돌 제거 + 내 돌이 남아 있으면 보너스 샷 |
| 상대 마지막 돌이 떨어짐 | 즉시 승리 |

## 마우스·터치 입력

### PC 마우스

1. 돌을 왼쪽 클릭한다.
2. 누른 채 발사 반대 방향으로 당긴다.
3. 점선은 짧은 초기 경로와 첫 접촉점까지만 보여 준다.
4. 당긴 거리가 파워 0–100이 된다.
5. `Shift`를 누르면 당기기 감도가 25%가 되고, 휠은 파워를 ±1 조절한다.
6. 마우스를 놓으면 발사한다. 우클릭 또는 `Esc`는 취소한다.

### 향후 터치

- 한 손가락 당기기가 방향과 기본 파워를 정한다.
- 두 번째 손가락의 짧은 상하 움직임이 미세 파워를 조절한다.
- 손가락이 돌과 접촉점을 가리므로 예상선과 게이지를 터치 위치 위쪽에 띄운다.

## 파워 게이지

| 구간 | 색 | 용도 | 위험 |
|---|---|---|---|
| 0–69 | 파랑 | 구출, 얇은 맞히기, 위치 조정 | 제거력이 낮음 |
| 70–89 | 금색 | 일반 공격, 뱅크, 연쇄 시작 | 과진입 가능 |
| 90–100 | 빨강 `MAX` | 최대 추진력, 일타다피 | 반동과 자기 추락 위험 최고 |

100에는 짧은 스냅 감각을 넣어 최대 파워를 의도적으로 고를 수 있게 한다. MAX는 랜덤 보너스나 유료 강화가 아니며, 같은 상태와 같은 입력은 같은 결과를 내야 한다.

## 아레나 아래의 위험

- **왕들의 용광로**: 쇠사슬 판 아래 용암 강, 화구, 무너진 성채와 용의 그림자.
- **폭풍선 정상**: 난간 없는 초고층 정비탑, 번개와 수천 미터 아래의 차량 불빛.
- **중력 우물**: 부서진 정거장과 파편을 끌어당기는 보라색 우주 소용돌이.

세 아레나는 랭크 물리가 동일하다. 위험한 배경은 긴장과 낙하 깊이를 만들지만 조준선을 가리거나 판에 랜덤 힘을 주지 않는다.

## 캐릭터 음성 방향

이 게임에서 귀여운 소리는 장식이 아니라 캐릭터 상품성의 핵심이다.

- 조준: 힘을 줄수록 짧은 숨, 이를 악무는 소리, 겁먹은 흡기.
- 충돌: 캐릭터 재질 위에 80–250ms의 짧은 개성 칩.
- 가장자리: 놀란 숨과 떨리는 한 음.
- 추락: 0.6–1.1초의 귀여운 비언어 비명 + 멀어지는 필터 + 마지막 `뿅/퐁/삡` 구조음.
- 보너스 샷: 공격 캐릭터의 0.3–0.6초 짧은 환호.

여러 돌이 떨어질 때는 비명을 60–90ms씩 어긋나게 하고 가까운 세 돌만 전체 음성을 사용해 알아들을 수 있는 코미디로 유지한다.

## 첫 버티컬 슬라이스가 증명할 것

1. 처음 보는 사람이 30초 안에 `선택 → 당기기 → 놓기`를 이해한다.
2. 파워 50, 80, 100의 차이를 시각과 소리만으로 구분한다.
3. 상대 돌 제거 뒤 자신의 턴이 유지된다는 사실을 첫 성공에서 바로 이해한다.
4. 가장자리에서 실제로 손에 땀이 나는 긴장이 생긴다.
5. 캐릭터 추락 비명이 반복되어도 귀엽고 수집하고 싶은 개성으로 들린다.
